gpb web UI — design preview

Static prototype of the design in design/WEB-DESIGN.md. Every page is plain HTML on one stylesheet (preview.css, the proposed real one) — click through with the nav exactly as the app would work. All names, photos and numbers are invented. Try it at 360px and with the OS in dark mode; both are part of the design.

Overview

overview.htmlThe healthy everyday state: backup totals with a meter, last run, session, review count.
overview-first-run.htmlFirst run — nothing followed, no runs; the empty state teaches the setup order.
overview-signed-out.htmlGoogle session dead: global danger banner, red session card, run stopped on auth_required.

Albums

albums.html132 albums + 49 shared bundles at real scale; filter box (type to try it), library card, sortable table, followed-first.
albums-empty.htmlFresh install — no albums fetched yet; empty state with the one action that helps.

Album grid

album-grid.htmlPicking mode, 200 cells: checkboxes (Tab + Space work), shift-click ranges, state marks, shimmer on still-loading cells, pager at both ends.
album-grid-empty.htmlOpened before anyone listed it: auto-listing banner over a skeleton grid instead of a blank page.

Activity

runs.htmlA run in flight (live card with moving counts) over the history table — ok, partial, auth_required, interrupted and drift rows, each with its detail line.
runs-empty.htmlNo runs yet.

Review

review.htmlBoth queues: new items in picked albums (approve/dismiss) and items gone from Google (acknowledge).
